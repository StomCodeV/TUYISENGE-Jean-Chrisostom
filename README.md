Welcome to the repository for my official professional portfolio and educational technology showcase website, deployed live at [chrisostom.vercel.app](https://chrisostom.vercel.app/).

## 🚀 About Me
* **Name:** TUYISENGE Jean Chrisostom (aka **StomCodeV** / **BLAD**)
* **Role:** Web Developer, Student Teacher at **TTC Muhanga**, and Founder of **iMENA Hub** / **iMENA Learn**.
* **Location:** Rwanda
* **Mission:** Building accessible educational technology and modern web solutions tailored for Rwanda and Africa.

## 🛠️ Tech Stack & Features
* **Frontend:** HTML5, CSS3, Modern JavaScript, Custom Glassmorphism UI.
* **Design & Typography:** Space Grotesk & Inter (Google Fonts), Font Awesome 6 icons.
* **SEO & Metadata:** Optimized with Open Graph tags, Twitter Cards, Schema.org JSON-LD Structured Data (`Person`, `Organization`, `WebSite`), and Google Analytics (`gtag.js`).
* **Hosting & Deployment:** Hosted and continuously deployed via **Vercel**.
